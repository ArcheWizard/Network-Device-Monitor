## Key Technical Decisions

### 1. **Optional Authentication**

- Chose to make authentication optional (disabled by default)
- Ensures backward compatibility with v0.1.0
- Allows gradual adoption

### 2. **JWT over Sessions**

- Stateless authentication
- Better for distributed systems
- No session storage required
- Easy to integrate with frontend

### 3. **Bcrypt for Passwords**

- Industry-standard hashing
- Built-in salt generation
- Configurable work factor
- Secure by default

### 4. **Three-Tier RBAC**

- Simple yet flexible
- Covers most use cases
- Easy to understand
- Room for expansion

### 5. **SQLite for User Storage**

- Consistent with device storage
- No additional dependencies
- Simple deployment
- Sufficient for small-medium deployments
